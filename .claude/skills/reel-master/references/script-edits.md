# The owner's script edits, and what they teach

Every time the owner changes a script (a line in the studio, a pasted full script, or a correction in chat), log it
here: what it was, what it became, and the lesson. **Read this file before writing any new script**, as
`carousel-edits.md` is read before a carousel. A lesson that holds twice moves into `storytelling.md` or
`kuwaiti-voice.md` as a rule.

## How to log an edit
- `### <date> · <film> <version> (<where: studio line / pasted script / chat>)`
- `- **was:** …` / `- **now:** …` (word for word)
- `- **Lesson:** …` (one sentence)
- `- **Status:** watching | became a rule (<file>)`
